# Бэктест SMA-стратегии на BTC

Проверка классической стратегии пересечения скользящих средних (SMA 20 / SMA 50) на дневных
свечах биткоина. Вопрос: обгоняет ли она обычную покупку и удержание.

## Что внутри

`sma_backtest.ipynb` — весь проект в одном ноутбуке:

1. Загрузка дневных свечей BTC с публичного API биржи (Bybit, при недоступности Binance или Yahoo)
2. Проверка качества данных: пропуски, дубли, разрывы в датах
3. Индикатор SMA 20 / SMA 50 и сигналы входа-выхода
4. Бэктест: исполнение на следующей свече, комиссия 0.1% за сделку
5. Метрики и сравнение с buy & hold
6. Просадки
7. Проверка чувствительности к параметрам

## На что обращено внимание

**Момент исполнения.** Сигнал считается по цене закрытия дня, но эта цена известна только
после его окончания. Поэтому позиция сдвинута на день вперёд (`shift(1)`). Без сдвига
получается заглядывание в будущее и завышенная доходность.

**Комиссии.** 0.1% за сделку списываются в каждый день смены позиции.

**Параметры.** 20 и 50 не подбирались под результат. Отдельно проверяется, есть ли вообще
устойчивая зона работающих значений, или хорошие цифры разбросаны по таблице случайно.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook sma_backtest.ipynb
```

При первом запуске данные скачиваются и кэшируются в `btc_daily.csv`, чтобы результаты
были воспроизводимыми. Чтобы обновить данные, удалите этот файл.
